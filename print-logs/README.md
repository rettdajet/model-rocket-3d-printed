# 3D Print Logs

Track each print: settings, time, success/failure, learnings.

## Print Log Template

Use this format for each print:

```markdown
### Print #000: [name]
- **Part:** [file name]
- **Date:** [Date]
- **Printer:** [printer used]
- **Settings:**
  - Material: PLA
  - Nozzle temp: 205°C
  - Bed temp: 55°C
  - Infill: 15%
  - Speed: 50 mm/s
  - Support: Yes
- **Print time:** X hours
- **Result:** Success /  Failed
- **Notes:** [What went well, what to improve]
- **Next print:** [What to try differently]
```
