# CAD Design Files

This folder contains all Fusion 360 CAD files for the rocket components.

## Files
- `nosecone_v1.f3d` - Pointed cone nose (in progress)
- `body_tube_BT80_hollow_complete` - Cardboard bodytube (in progress) 
- `fin_v1.f3d` - Triangular fin (planned)
- `fin_bracket_v1.f3d` - Fin reinforcement (planned)
- `engine_mount_v1.f3d` - Engine holder (planned)
- `avionics_bay_v2.f3d` - Sensor housing (planned)
- `parachute_bay_connector_v1.f3d` - Parachute connector (planned)
- `launch_controller_v1.f3d` - Launch box (planned)

## STL Files
See `stl-files/` folder for 3D-print-ready files.
